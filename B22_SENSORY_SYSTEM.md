# B22 — СЕНСОРНАЯ СИСТЕМА

## Минимум
В каждой важной сцене должны быть физическое присутствие и хотя бы один конкретный сенсорный якорь; в ключевых сценах — несколько каналов.

## Каналы
Запах / звук / свет / температура / фактура / вкус / телесная реакция / пространство.

## Принцип
Не перечислять ощущения. Использовать их для действия и эмоции.

## Пример функции
Холод может ограничить движение. Запах еды может вызвать воспоминание. Шум поезда может скрыть реплику.
