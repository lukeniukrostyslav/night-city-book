# B18 — FAIR PLAY / СИСТЕМА ПОДСКАЗОК

Для каждой крупной тайны создать отдельную таблицу: clue / chapter window / visible meaning / true meaning / false interpretation / payoff.

## Правила
1. Улика существует до раскрытия.
2. Улика не должна быть настолько очевидной, чтобы уничтожить интригу.
3. Нельзя менять значение факта задним числом без подготовки.
4. Герои могут ошибаться, но не должны становиться глупыми.
5. После раскрытия читатель должен иметь возможность восстановить цепочку.

## Контроль
Перед B26 все major mysteries должны иметь минимум несколько независимых подготовленных признаков.
