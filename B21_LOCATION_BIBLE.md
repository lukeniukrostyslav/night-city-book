# B21 — LOCATION BIBLE

Каждая локация получает: визуальный образ / запах / звук / температуру / социальную жизнь / сюжетную функцию / эмоциональную функцию / предмет или след / опасность.

## Основные места
Дом Вейлов / школа или учебная среда / место друзей / дверь / центральная площадь / рынок / гостиница / театр / вокзал / библиотека / мастерские / мост / канал / тоннели / железнодорожная линия.

## Требование
Ни одна локация не должна существовать только ради красивого описания.
