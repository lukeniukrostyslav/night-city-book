# B26 — ПОЛНАЯ АРХИТЕКТУРА 32 ГЛАВ + ЭПИЛОГ

## Статус
НЕ УТВЕРЖДЕНА. Этот документ является каркасом будущего проектирования, а не готовым планом.

## Требование
До написания романа нужно создать 32 главы + эпилог с для каждой главы: POV/локация/цель/конфликт/действие/улика/эмоциональное изменение/юмор/опасность/reward/финальный импульс.

## Трёхактный макро-ритм
Часть I — открытие и первый контакт.
Часть II — исследование, дружба, последствия, рост угрозы.
Часть III — семейная правда, исчезновение города, Восс, встреча с Даниэлем, моральный выбор.

## Критическое правило
Нельзя строить 32 главы как последовательный квест. Между погружениями обязательны дом, друзья, обычная жизнь, отношения и последствия.

## Перед утверждением
Проверить CHARACTER / WORLD / ADVENTURE / MYSTERY / EMOTION / RHYTHM / ORIGINALITY / COMMERCIAL.
