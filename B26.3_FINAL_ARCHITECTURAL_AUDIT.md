# B26.3 — ФИНАЛЬНЫЙ АРХИТЕКТУРНЫЙ АУДИТ

## Цель
Довести архитектуру 32 глав + эпилога до состояния, пригодного для B27, без преждевременного написания прозы.

## 1. Fair Play — контроль основных тайн

| Тайна | Ранние опоры | Ложное прочтение | Позднее значение |
|---|---|---|---|
| Почему Элиза реагирует на город | реакция на название/предмет Даниэля | просто страх за детей | она знала о связи Даниэля с городом |
| Почему исчез Даниэль | записи, маршруты, рассказы | он ушёл от семьи | он принял решения и не смог честно вернуться |
| Связь Даниэля и Восса | имена, предметы, свидетельства | случайное знакомство | совместное исследование и идейный конфликт |
| Почему исчезают районы | наблюдения, рассказы жителей, изменения маршрутов | случайный эффект города | системный процесс с человеческими последствиями |
| Восс хочет контролировать город | методы, сделки, давление | хочет просто разрушить город | контроль для предотвращения потери |
| Человек, похожий на знакомого | поведение, несоответствия, реакция других | найденный человек действительно тот | внешнее сходство не гарантирует идентичность |
| Возможность вернуть Даниэля | правила города, действия Даниэля, маршрут | город сам всё исправит | выбор остаётся за человеком |

Правило: ни одно ключевое раскрытие не должно зависеть от единственной поздней подсказки.

## 2. Локации — распределение по роману

Каждая ключевая зона используется минимум дважды или получает оправданную одноразовую функцию.

- Входной квартал — начало / позднее возвращение.
- Ночной рынок — знакомство / социальное изменение.
- Гостиница — человеческие истории / информация о Воссе.
- Театр — культура / свидетельство о Даниэле.
- Центральная площадь — переходы / первый колокол / кульминационное давление.
- Станция — поиск маршрута / финальное перемещение.
- Канал — исследование / опасность.
- Мастерские — механизм / материальные следы прошлого.
- Библиотека — исследование / проверка противоречий.
- Исчезающий район — наблюдение / последствия / кульминация.
- Тоннели — приключение / физическая цена.
- Железная линия — след прошлого / финальное движение.
- Старый мост — переход / эмоциональная сцена.
- Старые дома — семейные и человеческие истории / изменение восприятия.

Правило: эпизодический персонаж получает минимум одну отличительную черту действия/речи/поведения, но не требует отдельной сюжетной дуги.

## 4. Объём

Цель романа: 85 000–95 000 слов.

Рабочий ориентир:
- главы 1–8: ~20 000;
- главы 9–16: ~21 000;
- главы 17–24: ~22 000;
- главы 25–32: ~24 000;
- эпилог: ~1 000–1 500.

Итоговый объём будет определяться сценами, а не механическим заполнением квоты.

Средняя глава ориентировочно 2 500–3 000 слов, но важные приключенческие и кульминационные главы могут быть длиннее.

## 5. Распределение функций

- главы 1–8: человек → семья → друзья → нарушение → первый контакт;
- главы 9–16: исследование → расширение мира → Восс → первая трещина;
- главы 17–24: приключение → последствия → моральная цена → разделение;
- главы 25–32: правда → встреча → выбор → последствия → возвращение.

## 6. Контроль повторов

Проверено:
- нет двух последовательных глав с одинаковым доминирующим типом действия;
- опасность чередуется с исследованием и эмоциональными сценами;
- обычный мир не исчезает полностью;
- Ночной город не превращается в бесконечную экскурсию;
- Восс не появляется в каждой главе;
- Даниэль не становится единственным содержанием каждой сцены;
- юмор имеет разные источники;
- локации возвращаются с изменённым значением.

## 7. Контроль развития отношений

Ключевые изменения:
- Лео–Мира: доверие → конфликт → дистанция → совместное действие.
- Лео–Том: юмор → доказательство ценности → конфликт → самостоятельное действие.
- Лео–Элиза: доверие → подозрение → конфликт → правда → новая форма доверия.
- Лео–Даниэль: образ → надежда → сомнение → встреча → реальный человек → принятие выбора.
- Лео–Восс: интерес → осторожность → сделка → давление → идейное противостояние.

## 8. Production Gate B26

B26 считается готовым для B27, если:
- все 32 главы имеют функцию;
- у всех есть конфликт и изменение;
- основные тайны имеют ранние опоры;
- локации распределены;
- второстепенные персонажи распределены;
- объём имеет реалистичный диапазон;
- отношения развиваются;
- повторов без функции нет;
- финал подготовлен заранее.

B26.3 завершён.
