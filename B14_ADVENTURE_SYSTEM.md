# B14 — СИСТЕМА ПРИКЛЮЧЕНИЙ

Приключение — не бег по карте. Каждое крупное приключение должно включать цель, препятствие, физическое действие, выбор и последствие.

## Типы
Исследование / путешествие / погоня / спасение / проникновение / переход через опасную зону / поиск предмета / возвращение / случайная встреча / столкновение с Воссом.

## Обязательный эффект
Приключение меняет хотя бы одно: знание, отношения, риск, маршрут, семейную ситуацию или решение.

## Вариативность
Не повторять «вошли в город → нашли улику → убежали».

## Баланс
Между большими приключениями нужны обычная жизнь и последствия.
