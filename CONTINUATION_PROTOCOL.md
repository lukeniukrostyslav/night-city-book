# CONTINUATION PROTOCOL — ДЛЯ ЛЮБОГО НОВОГО CHATGPT

Если другой ChatGPT продолжает проект, он должен:

1. Прочитать PROJECT_STATE.md.
2. Прочитать MASTER_PROMPT.md.
3. Прочитать ARCHITECTURE.md, если он уже создан.
4. Прочитать CHARACTER_BIBLE.md.
5. Прочитать WORLD_RULES.md.
6. Прочитать MYSTERY_LEDGER.md.
7. Прочитать CHAPTER_STATUS.md.
8. Найти последний завершённый chapter-файл.
9. Прочитать предыдущую главу целиком перед написанием следующей.
10. Проверить, какие сюжетные факты уже установлены.
11. Не считать план утверждённым, если статус этого плана не указан как approved.
12. Не писать следующую главу, если обнаружено противоречие в архитектуре — сначала остановиться и обновить проектную документацию.
13. После написания сохранить файл в chapters/CHAPTER_XX.md.
14. Посчитать слова точно.
15. Обновить CHAPTER_STATUS.md.
16. Сделать отдельный commit.
17. Проверить сохранение файла.
18. Записать commit SHA.

## Главное
Источник истины — GitHub, а не память отдельного чата.

Нельзя говорить «сохранено», если GitHub commit фактически не создан.

Нельзя говорить «100%», пока критерии 100% не выполнены.

Нельзя продолжать старую архитектуру, если пользователь утвердил новую.

## Стартовая команда
Перед продолжением спроси себя:
«Какое последнее состояние проекта подтверждено файлами GitHub?»
И работай только от этого состояния.
